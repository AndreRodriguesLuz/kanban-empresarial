# 📋 CoreTask - Kanban Empresarial (Gestão Ágil)

Um sistema de gerenciamento de tarefas moderno em formato de quadro Kanban (estilo Trello), desenvolvido com o objetivo de otimizar o fluxo de trabalho interno de equipes que atuam em formato de trabalho remoto ou Home Office.

## 🚀 Demonstração (Veja funcionando ao vivo)
Você pode testar o sistema completo rodando diretamente na internet através do link: 
👉 [https://github.io](https://github.io)

## 🛠️ Tecnologias Utilizadas
*   **HTML5:** Estruturação semântica das colunas ágeis e formulários modais.
*   **CSS3 Moderno:** Interface responsiva com Tema Dark corporativo e componentes visuais dinâmicos.
*   **JavaScript Puro (Vanilla JS):** Lógica de negócios de ponta a ponta sem o uso de bibliotecas externas.

## ⚙️ Funcionalidades e Engenharia do Projeto
*   **CRUD Completo:** Criação, leitura, atualização e exclusão de tarefas em tempo real na interface (manipulação avançada do DOM).
*   **API de Drag and Drop Nativa:** Movimentação dinâmica de cards entre as colunas ("A Fazer", "Em Progresso" e "Concluído") via eventos do mouse.
*   **Persistência com LocalStorage:** Armazenamento estável de dados diretamente no navegador do usuário, retendo as tarefas mesmo após fechar a aba ou reiniciar a máquina.
*   **Categorização por Prioridade:** Renderização de bordinhas e badges neon sinalizando o nível de urgência da demanda (Baixa, Média e Alta).
